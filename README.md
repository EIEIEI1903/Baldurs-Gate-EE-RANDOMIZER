### Randomizer

Randomizer is an unofficial fan-made modification for Baldur's Gate that creates a different companion setup for each playthrough.

## Description

Randomizer randomly selects companions at the beginning of a game and removes the companions that were not selected.

This creates a different world state for each playthrough, making it possible to experience Baldur's Gate with different companion combinations and increasing replayability.

## Mod Companions

Randomizer can also detect and include companions added by other installed companion mods in the randomization.

This feature is optional. Depending on the selected configuration, you can:

Randomize only the original BioWare companions.

Include compatible companions from other installed mods in the randomization.

Randomize mod-added companions while removing all original BioWare companions.

This allows the companion pool to be tailored to the mods installed by the player.

## Installation

Download the latest release from the Releases page and extract the contents of the archive into your Baldur's Gate game directory.

Run the included WeiDU installer and follow the installation instructions.
