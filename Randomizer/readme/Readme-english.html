Randomizer

The Baldurs Gate Dice - V: 0.1

Install

This isn't a mod in the traditional sense, but rather an additional die designed to increase replay value. It's a very powerful tool that partially undermines the classic Weidu system.

For this reason, you should actually install this “mod” last! This is absolutely essential to ensure proper functionality. There are also other factors to consider!

Notice: We strongly recommend using the A7-DlcMerger by Argent77 for this mod, as this is the only way to ensure full functionality!

What does it do?

This mod makes the most of the fellowship-NPC you will meet on your journey optional. That means if they exist or you can meet them depends now on dice luck. That makes the accompany more meaningful because your partner are now valuable if you should only gamble a few of them. The philosophy behind it is more in line with BioWare's "Mass Effect" and "Dragon Age" series! From now on, you won’t find companions just around every corner! No! You’ll always play with only a certain number! There are three modes:

Mode 1 – The Basic Cast Randomizer: Here, the Fellowship Cast developed by BioWare is simply rolled at random. All installed mods are ignored. If you just want to randomly select the standard companions but still want to include all your modded companions, you should choose this mode.

Mode 2 – The Advanced Cast Randomizer: What makes this mod special, however, is the so-called Advanced Cast! It’s essentially the showpiece for which the mod was originally developed. The same rules apply as for the Basic Cast, but now almost all companions the player has previously installed are included in the roll. How many and which ones depend on chance as well as a predetermined ranking based on a complex ranking system I designed, taking into account rarity, race, class, power, and story presence. But you can sum it up like this: The more boring (fewer storylines/quests/romances/conversations), more villainous, and weaker a companion is—and the more human he or she is—the higher the probability of them appearing on the Sword Coast. So the probability of encountering an Indira (if available) is higher than that of encountering an Ayden or a Bristlelick. You’ve really hit the jackpot if you’ve installed Glam’s NPC Pack and then rolled the dice for it as well. The more NPC mods you have installed, the more fun it gets. The probability of rolling a rogue, pirate, or wanderer is higher than, for example, a powerful warlock or Sandra (not included). However, the average maximum number of companions remains the same, so having a higher number of companion mods doesn’t automatically mean you’ll roll more companions. In fact, the more companion mods you have installed, the lower the chance of rolling a BioWare NPC. So if you want maximum variety in your playthrough, you should choose this mode and install as many companion mods as possible beforehand. However, due to rule requirements, you need AT LEAST 3 companion mods to play this mode. Later versions of the mod may change this number, depending on the community’s feedback.

Mode 3 — The Basic Cast Remover: This tool is no longer part of the actual randomizer itself, but rather a tool for people who want to attempt a run exclusively with their modded characters, without the BioWare NPCs. Here, all BioWare NPCs are removed from the Basic Cast, so that, aside from the Core Cast, you’ll only encounter your modded companions.

Optional: The next release could implement a fourth option that only randomizes the Mod NPC's but leaves the Basic Cast untouched.

1) The mod works like a normal WEIDU Mod though it's a custom edition. Just put the Randomizer folder along with the Randomizer.exe into your Baldurs Gate directory (myPath...\Baldurs Gate Enhanced Edition) and start the Randomizer app. You can't use any other WEIDU version, than the RainerZufall edition. The mod would not work.

2) It's not essential right now but recommended to install the Argent DLC meger. In future releases this could become mandatory, to play the mod. The starting menu contains 3 entries. Choose ONLY one and install it only once! This is a very early version of the mod. Don't repeat the installation process especially for the second entry (extended Cast) to avoid any issues or bugs! If you want to remove the Randomizer again, read the uninstallation topic!

The options menu:

1] Start Basic_Cast Randomizer =

Enter ‘1’ and press the Enter key to install Module 1 and start the randomiser at the same time. Whilst the randomiser is running (= installing), you will be prompted to press the Enter key again. Press ENTER and let the programme run. It may take a while, depending on how many companion mods have been installed and how many are being removed. The installer will now install everything automatically. No errors should occur. If an error does occur – for example, because you forgot to install the SoD DLC Merger – Yeslic may be present. During installation, you will not receive any feedback on who has been selected and who hasn’t, or anything similar. Select this option if you ONLY want to randomise the core cast. Note that the mod only offers a selection of companions, usually between 8 and 13 characters. You won’t be able to find everyone in your playthrough! That’s the basic idea behind the mod! Who you meet on your journey is now left to chance.

2] Start Advanced_Cast Randomizer

Enter ‘2’ and press the Enter key to carry out the installation (using Module 2) and start the randomiser at the same time. Whilst the randomiser is running (= installing), you will be prompted to press the Enter key again. Press Enter and let the programme run. It may take a while, depending on how many companion mods have been installed and how many are being removed. The installer will now install everything automatically. No errors should occur. If an error does occur – for example, because you forgot to install the SoD DLC Merger – Yeslic may be present. During installation, you won’t receive any feedback on which mods have been selected and which haven’t, or anything similar. Select this option if you have installed at least 3 companion mods. Ideally, however, you should have installed at least 5–10+. IMPORTANT NOTE: Since the author of this Baldur’s Gate 1-ToB mod (who has only played it once in his life), has never played the third installment, and didn’t want any spoilers, a mechanism was specifically developed to PERMANENTLY remove the unselected companions from the WEIDU installation without having to modify the scripts of the respective mod authors. This is essential for proper operation! Future versions of this mod may, however, run on a standard WEIDU version under certain circumstances, where you can restore deleted companions. If you want to remove the randomizer later, you can do so without hesitation; however, the deleted companions will not be restored again(see uninstallation).

3] Start Base_Cast_Remover_Tool

Type in "3" and push "Enter" to install (with module 3) and start the Randomizer at the same time. You need at least 6 companion mods installed, to start the installation.Then the installer will install everything automatically.There shouldn't be any errors. If you get an error because you forgot to install an SoD DLC merger, it might happen that Yeslic will be still present. After installation every Basic_Cast BioWare companion should have been removed. Select this option if you only want to try a run with your modded companions (mostly -> see Mod Rules)

How to uninstall this mod?

To uninstall this mod, first launch the Randomizer app, type “u” on your console, and confirm by pressing “Enter.” The mod will then be removed, and the original NPCs will be restored.There should be no errors, provided that the randomizer was installed as the last mod.

WARNING!

However, if you installed the Randomizer with Module 2, all NPC mods that were not randomly selected by the Randomizer were uninstalled. If you now uninstall the Randomizer, even all traces of these NPC mods will be completely removed from the game’s memory, so a subsequent reinstallation should be possible without any problems. BUT: Afterward, you must reinstall all companion mods that you absolutely want to have in the game (i.e., launch each individual mod installer and reinstall the companion mod as if you had never run it before). This does not apply to mods that were installed after the Randomizer (see rule violation).

Rules of the Mod

Let’s move on to the most important part of this Readme: the mod’s rules! You’ve surely noticed that the mod significantly increases the difficulty, since you can no longer freely choose your companions based on their class and alignment, but must instead select from the pool of available NPCs and, from this smaller pool, choose the companions that suit you best based on their alignment, class, or playstyle. With a low roll and an unfavorable mod combination, this could—in the worst-case scenario—result in you having only 6 companions, of whom you might be able to use 4, even though this scenario is extremely unlikely. But how exactly are the companions classified?

The Worldstate is based on 4 groups. These are:


Group 1 — the main characters: This group is so central to the plot of Baldur's Gate that it ALWAYS exists. This group includes:

-The player

- Imoen

- optional: all Gary and Mary Sues who drastically alter or influence the plot (e.g., Sandra or Sandrah), whether you like it or not.


Group 2 – The CoreCast: Anyone who has read the README carefully will have come across the term “CoreCast.” This group is characterized by a significant role in the main or side plot, has a visual and narrative presence in the game world, or—much like Group 1—serves as a plot anchor (SoD).This group is almost on par with Group 1 in every respect. It will also (almost) NEVER be part of this randomizer. The difference from Group 1 lies more in the varying degrees of importance regarding the points mentioned, which are reflected in the hierarchy within this group. This group includes:

1. Skie Silvershield + brother (Group 3—SoD and Del’Vortel: Cost of One Girl’s Soul) + Eldoth (sneaked from Group 3 into Group 2)

1. Captain/Major Shael Corwin (“SoD” and “Love Conquers All”) as well as Lady Shining/Caelar Argent (“SoD” and “Love Conquers All”—technically Group 1, but acceptable in Group 2 from the randomizer’s perspective based on pure playability)

1. Jaheira(BG1,2,3) and Khalid are, due to their relationship with Gorion and the many other anchor points in the main story, the most important representatives of Group 2 along with the other pairings.

1. Yoshimo (BGII)

2. SoD-Only: Neera (otherwise group 3)

2. SoD-Only: Baeloth and M'Khin (otherwise group 3)

2. Sarevok (BGII): From any Sarevok mod

2. Bodhi (BGII): From any Bodhi mod

2. JonlethI(BGII): From any Irenicus mod

2. The MDE Trio (was experimentally taken in group 3 during Randomizer v0.1.0 -> own rule violation since Minsc needs a removal mod in BG3)

2. Viconia (was experimentally taken in group 3 during Randomizer v0.1.0 -> own rule violation, since she needs as far as I know a HUGE mod reflecting this state in BG3)

3. Captain Brage (Jastey's: Brage's Redemption)—even though I'd never played this mod, this character was such a major part of the story that I thought he was a member of the BioWare cast I'd missed.

3. Solaufein Mod (Argent77)

3. Kelsey Mod(jcompton and Ghreyfain)

3. BGII Group1 (Cernd, Valygar, Nalia, HaerDaelis - only experimentally)

4. BGII Group2 (Anomen,Keldorn,Mazzy,Jan)

4. Kagain the first of the inhabitants

4. Hexxat (BG2 secret char) is the second "inhabitant"

5. Branwen (a sort of 0.5 inhabitant) was already implemented "dirty" into group 3 during the development of Randomizer v0.1.0

Everyone lower than rank 3 of Group two can join group three in later updates of Randomizer if this is requested! Rule violations made by me can be fixed in either in BG3 (after I play it) or a later patch of Randomizer mod.


Group 3 – Randomizer group: The Randomizer group currently consists of two subgroups, and is going later to consist of three

  • 1) BasicCast: All BioWare companions(who aren't already in Group 1 or 2) are included here
  • 2) AdvancedCast: All BioWare companions(who aren't already in Group 1 or 2) and all mod companions are included here
  • 3) ImprovedCast: (not currently included)- Only mod companions are included here


Group 4 – Blanky group (currently not included - AdvancedCast only ) It's intended that there is a fourth group of so called blank chars made by me. These are especially weak or annoying human hirelings or landfolk that can't become stronger than Level 6 (also in Baldurs Gate 2) They are going to fill the empty places if the player does not install enough Mod companions for module 2 AdvancedCast. It's going to remain rare (50%) that they'll be rolled

Rule violation:

There are always cheaters out there who want to bend the rules of the game. With this mod, that’s possible, of course, by simply installing another companion mod after installing this one. That companion will then always appear, of course. The same applies to companions that, for whatever reason, weren’t included in this mod. Doing so diminishes the fun of the game because it circumvents the randomness and renders the mod’s purpose meaningless. Please don’t do that! Always install this mod last! Using Argent77's A7-NPCGenerator also constitutes a violation of the rules, since the custom companions created with the generator cannot, of course, be selected by the randomizer. If you still wish to use this tool, please do not create more than one custom NPC so as not to jeopardize the fun of the game.
